เริ่มใช้งาน

SNTalkBot Web Manager ใช้สร้างและดูแลบอตผ่านเว็บ โดยไม่ต้องพิมพ์คำสั่ง Linux สำหรับงานทั่วไป

บัญชีและสิทธิ์

Super Admin จัดการผู้ใช้ ระบบ อัปเดต และ Migration ได้ทั้งหมด ผู้ใช้ทั่วไปเห็นเฉพาะบอตของตนเอง ชื่อบัญชีเว็บกับ TeamTalk ไม่จำเป็นต้องเหมือนกัน

สร้างบอต

กด “สร้างบอต” เลือกประเภท กรอก TeamTalk server และข้อมูลของบอต ผู้ใช้ทั่วไปต้องกรอก TeamTalk Administrator username/password เพื่อยืนยันสิทธิ์บนเซิร์ฟเวอร์นั้น ระบบใช้รหัสผ่านเพื่อตรวจครั้งเดียวและไม่บันทึกรหัสผ่านชุดยืนยันไว้

แดชบอร์ดและสถานะสด

แดชบอร์ดบอกว่าบอตกำลังรันหรือหยุด ห้องปัจจุบัน จำนวนคนในห้อง จำนวนคนทั้งเซิร์ฟเวอร์ Administrator ที่ออนไลน์ และสถานะ Player/Manager เท่าที่บอตรายงานได้ เมื่อบอตหยุด ข้อมูลสดเก่าจะไม่ถูกนำมาแสดงเป็นข้อมูลปัจจุบัน

เริ่ม หยุด รีสตาร์ต และลบ

ใช้ปุ่มบน Dashboard หรือหน้ารายละเอียดบอต ปุ่มลบจะแสดงเฉพาะเมื่อบอตหยุดแล้ว และต้องพิมพ์ชื่อ instance ให้ตรงก่อนยืนยัน ระบบสำรองข้อมูลก่อนลบ

งานที่ใช้เวลานาน

งานอย่างอัปเดต ตรวจระบบ ตรวจ cookies หรือ Migration จะแสดงในหน้าต่างงานแบบ dialog พร้อมสถานะสดและปุ่มคัดลอก คุณปิด dialog เพื่อทำงานต่อในหน้าเดิมได้ งานเบื้องหลังยังทำต่อจนจบ

ย้าย TTMediaBot เก่า

เมนู “ย้าย TTMediaBot” ใช้สำหรับ Super Admin ตรวจและนำเข้า config รุ่นที่รองรับ แนะนำให้ทำ Dry run ก่อน ของเดิมจะไม่ถูกลบ และมีรายงานผลการย้ายเก็บไว้

อัปเดต

หน้า “ระบบ/อัปเดต” ใช้อัปเดต Web Manager, TTUHelper และ SNTalkBot image ได้ เมื่ออัปเดต Web Manager หน้าเว็บจะพยายามคงการเชื่อมต่อไว้และแจ้งเมื่อรุ่นใหม่กลับมาออนไลน์

Reverse Proxy

สำหรับ CloudPanel หรือ reverse proxy อื่น ให้ชี้โดเมน HTTPS มาที่ http://127.0.0.1:28765 เท่านั้น ไม่ต้องเปิดพอร์ตนี้สู่ Internet โดยตรง

เมื่อพบข้อผิดพลาด

หากหน้าเว็บแสดงข้อผิดพลาด ให้ลองเปิดหน้าเดิมอีกครั้ง หากยังเกิดซ้ำให้ส่ง Request ID ที่หน้า error ให้ผู้ดูแลระบบ ไม่ควรส่ง password, token หรือ cookies ไปพร้อมรายงาน
