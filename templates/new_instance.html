สร้างบอตใหม่

เว็บจะสร้าง instance จาก config จริง แล้วเริ่มบอตชั่วคราวเพื่อตรวจว่า TeamTalk username ของเจ้าของเป็น Administrator ที่ออนไลน์อยู่จริง บนเซิร์ฟเวอร์นั้น บัญชีของบอตเองจะไม่นับเป็นหลักฐาน

ประเภทบอต
Linux: ใช้ตัวพิมพ์เล็ก a-z, เลข 0-9, จุด, ขีดกลาง หรือขีดล่างเท่านั้น; ขึ้นต้นด้วยตัวอักษร/เลข; สูงสุด 63 ตัว; ห้ามเว้นวรรค, slash, backslash หรืออักขระพิเศษ เพื่อให้ชื่อโฟลเดอร์, container และคำสั่งตรงกันทุกครั้ง auto = แสดงประเภทบอตและคำแนะนำ h ต้องเป็นบัญชีมนุษย์ของเจ้าของ Web account นี้และต้องออนไลน์อยู่ตอนสร้าง ระบบจะตรวจจากรายชื่อ Administrator ที่บอตเห็นจริง และห้ามใช้ username เดียวกับบอต TeamTalk username ของเจ้าของจะถูกเพิ่มให้อัตโนมัติ
