ข้อความ Global Broadcast ส่วนกลาง

ข้อความทั้งหมดอยู่ในรายการส่วนกลางชุดเดียว เก็บใน SQLite ของ Web Manager และส่งเฉพาะ Manager/Full Bot ที่เปิด [global_broadcast] enabled = True แต่ละบอตกำหนดช่วงเวลาเองได้ 1–10,080 นาที และเลือก tts_enabled = True ได้หากต้องการพูดข้อความเดียวกันด้วย TTS

การส่งใช้การสุ่มแบบไม่ซ้ำในหนึ่งรอบ: ระบบสุ่มจากข้อความที่ยังไม่ได้ส่งของบอตนั้นจนกว่าจะครบทุกข้อความที่เปิดใช้ แล้วจึงเริ่มสุ่มรอบใหม่ ไม่เรียงตามหมายเลขและไม่ส่งข้อความเดิมซ้ำก่อนครบชุด

เพิ่มข้อความ
